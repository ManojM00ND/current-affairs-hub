17Newton's Laws of Motion

LawStatement
First LawAn object at rest stays at rest, and an object in motion stays in motion unless acted upon by an external force. (Law of Inertia)
Second LawForce = Mass × Acceleration (F = ma)
Third LawFor every action, there is an equal and opposite reaction.

  • Vitamins: A → Night Blindness · B1 → Beriberi · C → Scurvy · D → Rickets · K → Bleeding
  • Diseases: Malaria = Protozoa (Plasmodium) · AIDS = Virus (HIV) · TB = Bacteria (Mycobacterium)
  • Blood: Universal Donor = O negative · Universal Recipient = AB positive · pH = 7.4 · RBC life = 120 days
  • SI Units: Force = Newton · Energy = Joule · Power = Watt · Pressure = Pascal · Frequency = Hertz
  • Speed: Light = 3 × 10⁸ m/s · Sound = 343 m/s (air)
  • Audible Range: 20 Hz – 20,000 Hz · Ohm's Law: V = IR
  • Newton's Laws: 1st = Inertia · 2nd = F = ma · 3rd = Action & Reaction
  • Chemistry Formulas: Baking Soda NaHCO₃ · Washing Soda Na₂CO₃ · Plaster CaSO₄·½H₂O · Quick Lime CaO · Salt NaCl · Vinegar CH₃COOH · Laughing Gas N₂O · Dry Ice CO₂
  • pH: Acid < 7 · Base > 7 · Neutral = 7
  • Gases: Balloons = Helium · Lights = Neon · Welding = Argon
  • Computer: CPU = Central Processing Unit · RAM = Random Access Memory · ROM = Read Only Memory · OS = Operating System
  • Networks: LAN = Local · WAN = Wide · MAN = Metropolitan · WWW = World Wide Web
  • Shortcuts: Copy = Ctrl+C · Paste = Ctrl+V · Cut = Ctrl+X · Undo = Ctrl+Z · Redo = Ctrl+Y · New Slide = Ctrl+M · Font Dialog = Ctrl+D
